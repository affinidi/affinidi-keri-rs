# affinidi-keri

High-level [KERI](https://keri.one/) identity management, part of
[affinidi-keri-rs](https://github.com/affinidi/affinidi-keri-rs).

- `Hab` — a single identifier: inception, rotation, interaction, signing.
- `Habery` — a registry of identifiers over a shared store.
- `direct` — direct-mode message exchange.
- `Judge` — duplicity detection across competing key event logs.
